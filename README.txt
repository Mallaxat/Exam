ЛЕПЕСТОК — многостраничный учебный сайт

Откройте index.html. Страницы работают без сервера и без интернета.

Страницы:
index.html — главная, подборки, карточка-образец, подарочный баннер, отзывы.
catalog.html — каталог с фильтрами, сортировкой и одной карточкой-заглушкой.
product.html — образец страницы букета, состав и уход.
cart.html — образец заполненной корзины с одним товаром.
about.html — история мастерской и отзывы.
delivery.html — доставка, оплата, iframe для карты, шаги заказа и FAQ.
contacts.html — блоки контактов без вымышленных телефонов и адресов.

Стили:
style.scss — исходник с переменными палитры.
style.css — готовый CSS, подключённый на всех страницах.
assets/ — локальные SVG-иллюстрации.

HTML оформлен с переносами строк и отступами в два пробела. В стилях каждое свойство на отдельной строке. Имена классов и нужных ID — camelCase.

КАРТА
В delivery.html найдите iframe с title="Карта зоны доставки по Санкт-Петербургу".
Замените src="about:blank" ссылкой для встраивания от сервиса карт.
Удалите соседний div с классом mapPlaceholder: он сейчас закрывает пустой iframe заглушкой.
Обычная ссылка на страницу карты может не поддерживать встраивание: используйте адрес из кода «Поделиться / Встроить карту» выбранного сервиса.

ДАЛЬНЕЙШЕЕ ПОДКЛЮЧЕНИЕ JS
В catalog.html контейнер #productList предназначен для карточек из базы.
article.productCard — образец карточки, название ведёт на product.html.
В product.html — пример данных одного товара.
В cart.html — только макет корзины; счётчик в шапке пока статичный.
Поиск, фильтры, сортировка, корзина, избранное и профиль не содержат бизнес-логики. Кнопки оформления не отправляют данные.
Переходы между страницами, ссылки по разделам и раскрытие FAQ работают средствами HTML.
Шапка и подвал повторяются в HTML каждой страницы, сборщик не нужен.

Для компиляции после изменения SCSS при установленном Dart Sass:
sass --watch style.scss:style.css

Отзывы и товар демонстрационные. Иллюстрации созданы для макета.
