ЛЕПЕСТОК — сайт цветочной мастерской

Запуск
1. Откройте папку проекта через Live Server и перейдите на index.html.
2. Для оформления заказов запустите Node.js из корня проекта: node data/server.js
3. Сервер принимает заказы на порту 3000 и сохраняет их в data/ReadyOrder.json.

Страницы
index.html — главная страница, подборки букетов и отзывы.
catalog.html — каталог с фильтрами и сортировкой по цене.
cart.html — корзина и форма заказа с выбором адреса.
about.html — о мастерской.
delivery.html — условия доставки, карта и ответы на вопросы.
contacts.html — контакты.

Структура
style.scss — исходник стилей, style.css — файл, подключённый на всех страницах.
scripts/UI/ — скрипты страниц и общие функции.
data/ — JSON с цветами, категориями и адресами, а также сервер заказов.
assets/ — изображения и иллюстрации.

Для компиляции после изменения SCSS при установленном Dart Sass:
sass --watch style.scss:style.css
